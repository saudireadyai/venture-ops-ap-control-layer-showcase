## Requirements and boundaries

- Node.js 22+ and npm are required to build. Installing dependencies requires internet access. Serve the built application through a web server; do not open `index.html` directly from disk.
- XLSX imports require **one visible values-only worksheet**. Formula cells, hidden rows/columns and merged cells are rejected. Legacy XLS compatibility is not established.
- Import limits: **10 MiB, 10,000 records and 128 columns**.
- Inputs are processed in the browser. Exports and reviewer checkpoints are not encrypted. Reloading may discard unsaved work.
- This is a human-review application, not a complete accounting system or hosted SaaS. It does not authorize payments, update an ERP, provide a shared cloud account system, establish fraud or guarantee financial recoveries.
- Review results before acting on them. No security, regulatory or accounting certification is claimed.
